# Nuavo 해커톤: 고객 만족도 예측

항공사 고객 설문 데이터를 다룬 학습 프로젝트입니다.

## 실제 파일

- `data_make.ipynb`: 데이터 전처리 실험.
- `base_code.ipynb`: 모델 학습과 실험 코드.
- `requirements.txt`: 당시 사용한 패키지 목록.
- `best_hyperparameters.txt`: 당시 저장한 실험 설정.
- CSV와 `.pth` 파일: 당시 입력·제출·모델 산출물. 새 평가에서 재검증한 결과가 아닙니다.
- `img/`: 실험 관련 그림.

## 검토 방법

두 노트북의 실행 순서와 데이터 경로를 먼저 확인하세요. 노트북을 재실행하려면 별도 Python 환경에서 `requirements.txt`의 의존성과 원본 데이터 이용 조건을 확인해야 합니다. 이 저장소에는 `train.py`와 `sweep_config.yaml`이 없으며, 한 명령으로 재현되는 학습 도구를 제공하지 않습니다.

README에 있던 검증 정확도는 이번 정리에서 재현하지 않아 대표 성능 수치로 제시하지 않습니다. 노트북·산출물·기존 커밋은 보존합니다.
